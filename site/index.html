Osiris

A Linux operating system with AI built in.

Based on Arch Linux, with the Cinnamon desktop. Ask the AI to change how your desktop looks, or to write small apps for you. The apps it writes show up in your menu and match your theme.

Get Osiris View the code

Early development (alpha). Free and open source.

The AI

Press Super + A and a sidebar opens where you can type to the AI. It is called Osiris, like the system.

Ask it for an app, say a Pomodoro timer, and it writes one. Try it, then install it into your applications menu and pin it to the dock. It writes Python, C or C++, Rust, Go or JavaScript.

Ask for a new look, or a moving wallpaper, and it makes one and puts it on your desktop. After every change there is an Undo button.

The AI can only do what Osiris allows: look around, make changes that can be undone, and edit the code of the apps it wrote. Anything else is refused, and you see what it tried.

Themes

A theme sets the colours of everything at once: apps, window borders, the panel, the dock, the app launcher, the terminal, folder icons and the wallpaper. Apps the AI writes follow it too. Switching is instant, no logging out.

Press Super + T to flip through the seven themes that come with Osiris, or make your own from a colour or a picture.

Wallpapers move. Each one is a small program on your graphics card, animating slowly in the theme's colours.

Your code

Each app the AI writes is a folder in ~/Code, kept in git, so you can see every change it made and carry on in any editor.

Your AI

The AI runs through opencode. Connect the provider you want, with your own account or key.

Your settings

Updating Osiris never overwrites your theme, your dock, your terminal settings or files you have edited.

Installing

The live ISO starts the full desktop with an Install Osiris icon on it. The installer asks for your region, disk, filesystem, encryption and account, then uses Arch's own archinstall to do the work.

Wipe a disk or install next to another system, use ext4 or btrfs, and encrypt the system if you want. It works on BIOS and UEFI computers.

Get Osiris

There is no published ISO yet. Until there is, you can build one on an Arch Linux machine with archiso installed:

git clone https://github.com/alexanderwanyoike/osiris
cd osiris
python3 iso/repo.py
sudo python3 iso/profile.py

Try it in a virtual machine before trusting it with a disk you care about. The README has the details.
