Osiris

An AI operating system.

Osiris is a Linux desktop you can ask for things. Ask for an app and it writes one. Ask for a new look and the whole desktop changes with it. Built on Arch Linux and Cinnamon, using an AI model from a provider you connect, such as OpenAI.

Get Osiris View the code

Early development (alpha). Free and open source.

Ask for it

Press Super + A and Osiris opens beside your desktop. Type what you want.

Apps

Ask for an app, say a focus timer, and Osiris writes it, tests it and shows it on a card. Try it, then install it into your applications menu and pin it to the dock.

It writes Python, C or C++, Rust, Go or JavaScript, and its apps follow your theme like everything else.

Looks

Ask for a calm theme for working late, or rain running down the window as a wallpaper, and it makes one and puts it on your desktop. Every change comes with an Undo button.

Work beside it

Expand Osiris to fill the screen. Next to the conversation, the Canvas shows the code of the apps it writes, what each question changed, a terminal and a browser.

Type @ to add a file to a message and / to use a skill. Connect MCP servers in Settings to give it more tools.

One look

Everything on screen looks like one system, the apps Osiris writes included. Change it in one press, without logging out.

Themes are the colours

A theme colours everything at once: apps, window borders, the panel, the dock, the launcher, the terminal, folder icons and the wallpaper.

Press Super + T to flip through the seven that come with Osiris, or make your own from a colour or a picture.

Skins are the shape

A skin sets corners, buttons, title bars, the panel, the dock, fonts and icons, in whatever colours the theme gives it.

Press Super + S to flip through the seven that come with Osiris, import one you downloaded, or ask Osiris for one.

Yours

What Osiris makes belongs to you, and so do the choices you make.

Your code

Each app Osiris writes is a folder in ~/Code, kept in git, so you can see every change and carry on in any editor.

Your model

Osiris runs on opencode. Connect the AI provider you want, with your own account or key.

Your settings

Updating Osiris never overwrites your theme, your skin, your dock, your terminal settings or files you have edited.

Get Osiris

Version 0.4.0, about 2.8 GB. Try it in a virtual machine before trusting it with a disk you care about.

Download the ISO Checksum

Check the download, then write it to a USB stick. Replace /dev/sdX with your stick; everything on it is erased.

sha256sum -c osiris-0.4.0-x86_64.iso.sha256
sudo dd if=osiris-0.4.0-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

The stick starts the full desktop with an Install Osiris icon. The installer asks for your region, disk, filesystem, encryption and account, then uses Arch's own archinstall. It works on BIOS and UEFI computers, can install next to another system, and can encrypt it.

Or build it yourself on Arch Linux; the README explains how.
